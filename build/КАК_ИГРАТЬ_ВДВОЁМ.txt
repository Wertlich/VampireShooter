VAMPIRE SHOOTER — как играть вдвоём
=====================================

ВАЖНО: запускать нужно из ПАПКИ ЦЕЛИКОМ (VampireShooter_win64), а не один exe.
В папке рядом с VampireShooter.exe должны лежать:
  addons\godotsteam\win64\libgodotsteam.windows.template_release.x86_64.dll
  addons\godotsteam\win64\steam_api64.dll
  steam_api64.dll
  steam_appid.txt
Если скопировать только exe — игра запустится, но Steam-лобби не будет.

1. Запусти VampireShooter.exe.

2. ХОСТ (кто создаёт игру):
   - главное меню -> ОНЛАЙН -> строка «Твой IP для друга» (например 192.168.1.10)
   - нажми «СОЗДАТЬ ХОСТ»
   - Windows спросит про фаервол — разреши доступ для частных сетей.

3. ГОСТЬ:
   - главное меню -> ОНЛАЙН
   - в поле «IP хоста» введи адрес хоста
   - нажми «ПРИСОЕДИНИТЬСЯ»

4. Через Steam (если Steam запущен и вы в друзьях):
   - хост: «СОЗДАТЬ ЛОББИ STEAM» -> «ПРИГЛАСИТЬ ДРУГА» (оверлей Shift+Tab)
   - друг принимает приглашение, адрес подставится сам.

Если что-то не работает:
- «Твой IP для друга: нет сети» или адрес 169.254.x.x — компьютер не получил
  адрес от роутера. Подключи Wi-Fi/кабель заново. 169.254.x.x — служебный адрес,
  по нему никто не подключится.
- «STEAM недоступен: Steam-модуль не найден» — рядом с exe нет папки addons.
- «STEAM недоступен: Steam не запущен» — открой клиент Steam и войди в аккаунт.
- «Сервер не ответил» — фаервол на машине хоста, разные сети, или хост не нажал
  «Создать хост».

Интернет без проброса портов: используйте общий виртуальный адрес
(Radmin VPN / ZeroTier / Tailscale) — тогда «IP для друга» будет из этой сети
и всё заработает как в локальной.

Управление:
  WASD — ходьба, мышь — обзор, ЛКМ — стрельба, ПКМ — прицел,
  R — перезарядка, Shift — бег, Пробел — прыжок, 1-7 — оружие,
  колесо — следующее оружие, Esc — пауза и настройки.
