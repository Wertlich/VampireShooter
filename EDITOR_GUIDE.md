# Редактирование игры в Godot

## Мобы

Открой `scenes/enemy_skeleton.tscn` (или другую `enemy_*.tscn`).

- Корневой узел: здоровье, скорость, урон, дистанции, задержки атаки,
  снаряд, анимации и варианты внешности находятся в Inspector.
- `Collision`: форма и положение коллизии редактируются в 3D.
- `Model`: модель; зомби выбирают модель из массива `Variants` при запуске.
- `Behavior`: компонент поведения. `Attack Style` выбирает ближний/дальний
  бой; `Detection Range` ограничивает дистанцию реакции; `Retarget Seconds`
  задаёт частоту выбора ближайшего игрока; `Turn Speed` — скорость поворота.
- `Enabled`, `Movement Enabled`, `Attacks Enabled` позволяют сделать
  пассивного моба, неподвижного стрелка или преследователя без атаки.

При наличии `Behavior` тип атаки берётся из него, а не из `Mode` корня.
Узел можно добавить вручную: Add Node → EnemyBehavior, прямым ребёнком моба.
Используй один Behavior на моба. Без него работает прежнее поведение.
Сигнал `state_changed` сообщает Idle / Move / Attack / Dead; текущее состояние
видно в Remote Inspector во время игры. Алгоритмы состояний пока остаются
в GDScript: это компонент настройки поведения, не граф произвольных переходов.

## Волны

В `scenes/main.tscn` выбери `WaveManager` → Wave Curve → Compositions.
Разверни ресурс нужной волны: `Wave` — номер, остальные поля — веса типов
врагов. Например, Skeleton = 1, Zombie = 1 означает равные доли.
По умолчанию заполнены прежние девять составов. Можно добавлять ресурсы
WaveComposition. Номера должны быть уникальными: используется первое совпадение.
Все нулевые веса дают скелетов. `Boss Wave` имеет приоритет над составом.
Количество и интервалы регулируются остальными полями WaveManager.
При совместном использовании ресурса сделай Make Unique для независимой копии.

## Карта

Открой `scenes/cemetery.tscn` (в `main.tscn` она подключена как `Cemetery`):

- `Ground` — трава и её коллизия; `Paths` — земляные дорожки.
- `Fence` — 47 модульных секций полуразрушенного забора + коллизия по периметру.
- `Churches/ChurchIntact` и `Churches/ChurchRuined` — две церкви; внутри каждой
  есть `Collision` с полом, стенами, алтарной стеной и входным пандусом.
- `Lamps/StandingLamp_*` — уличные фонари (модель из `models/lamp`), а
  `Lamps/HangingLamp_*` — подвесные клетчатые лампы из `lamp for dom`.
  Свойства мерцания и длина цепи — в инспекторе `CemeteryLamp`.
- `Graves` и `Props` — надгробия и крупные памятники. Их коллизия собрана в
  общем `PropCollision` (StaticBody3D): туда же входят деревья, модели ламп,
  обломки руин и воротные столбы. У ворот оставлен проход.
- Ночное небо, туман и направленный свет луны находятся в `main.tscn`
  (`WorldEnvironment` и `Moon`), а не в самой карте.

Чтобы пересобрать карту после правок Blender-ассетов или расстановки:

```powershell
$blender = 'D:\Steam\steamapps\common\Blender\blender.exe'
$godot = 'D:\GodotMCP\Godot\Godot_v4.7.2-stable_win64_console.exe'
& $blender --background --factory-startup --python tools\blender_cemetery.py
& $godot --headless --path . --script res://tools/build_cemetery.gd
```

Скрипт `tools/build_cemetery.gd` — источник расстановки; правки прямо в
`cemetery.tscn` пропадут при следующей пересборке. Церкви и лампы вынесены в
`scenes/cemetery/*.tscn`, поэтому их можно править отдельно.

Если меняются GLB церквей, пересобери их точную коллизию:

```powershell
& $godot --headless --path . --script res://tools/build_church_trimesh.gd
```

Лестница и верхняя площадка описаны в `LADDER_SPECS` / `LANDING_SPECS` внутри
`build_cemetery.gd`; вход в церковь вырезан из trimesh, чтобы не застревать на
ступеньках. Скорость лазания настраивается в инспекторе `Player > Ladders`.

## Границы переноса

Оружие уже имеет собственные сцены и экспортируемые параметры. Интерфейс,
карточки улучшений, сетевой код и внутренние алгоритмы боя продолжают
использовать существующие скрипты. Новые алгоритмы требуют GDScript;
описанные настройки меняются без редактирования кода.
